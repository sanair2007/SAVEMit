# Changelog

All notable changes to SAVEMit are documented here.

## 0.1.0 - 2026-08-08

- Added a local stdio MCP server for Node/npm dependency investigations.
- Added Antigravity, Codex, and GitHub Copilot integration packages.
- Added `.savemit-policy.json` for package blocks, minimum-priority thresholds, and major-upgrade controls.
- Added `get_policy_decision` and `get_report` MCP tools.
- Added Docker-based dependency validation and demo repositories for common outcomes.
